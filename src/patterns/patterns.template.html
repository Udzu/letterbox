Word list

Load a text file with one word or phrase per line to list the ones the pattern matches. Click a match to add it to the test strings and see how it matches. The list is kept in this browser only (but shared with the other pages).

Patterns match whole strings, so there are no anchors: unlike in most regex dialects, ^ means interleaving (see below), not the start of the string. All ASCII punctuation except ' is reserved, so write \., \-, \\ and so on to match it literally.

Characters
a \* \n \u{e9}a character
.any character
[abc] [a-z] [^a-z]character classes ([] matches nothing)
\d \w \san ASCII digit; an ASCII letter or digit, or _; ASCII whitespace. \D, \W and \S are the opposites, and all of these work inside classes too, as in [\d_]
\p{L} \P{L}a character with or without a Unicode property, as in JavaScript (\p{Lu} is an uppercase letter, \p{Script=Greek} a Greek character)
@any word in the word list, if one is loaded
\Q...\Ethe characters in between, taken literally (\Qe.g.\E matches e.g.)
Repetition and sequence
P* P+ P?0 or more; 1 or more; 0 or 1
P{n} P{n,} P{m,n} P{,n}n; n or more; m to n; up to n
PQP followed by Q
Combining strings
P<Q P>QP inside Q; P outside Q (o+<l+ matches loool)
P<<Q P>>Qstrictly inside or outside, with the outer part on both sides
P^QP interleaved with Q (the^A+ matches tAAhAe)
P<^Q P>^Qinterleaved strictly inside or outside, with the outer part at both ends
P#Q P##QP alternating with Q, in either order; with P first (U+##w+ matches UwUwU)
P-Q P_-QP with Q removed from the end or the start ((the|a)-. matches th)
P-opQP with Q removed according to any operator above: -< -> -<< ->> -^ -<^ ->^ -# -## _-## (Madrid-^.. matches Mdrd)
(?w:S/P/Q) (?u:S/P/Q)P and Q combined by a custom split S, a pattern over L (for P's characters) and R (for Q's), as in the operators above; P with Q removed by S ((?w:L+R+L+/the/[a-z]+) matches tithe)
Logic
!Panything P doesn't match
P&Qboth P and Q
P|Qeither P or Q
(P)grouping
Lookarounds (unlike in PCRE, these only see their own group or operand, so can't look outside it)
(?=P) (?!P)what follows starts with P; doesn't ((?!the)[a-z]+ matches tea but not then)
(?<=P) (?<!P)what precedes ends with P; doesn't ([a-z]+(?<!ing) matches sang but not sing)
\b \Ba word boundary (\w on one side only); not one (.*\bcat.* matches a cat but not concat)
Names
(?<v>P) (?&v)P, named v; P again (the same pattern, not the same text). (?<v>P){0} names P without matching it ((?<c>[^aeiou])[aeiou](?&c) matches cat)
Modifiers and transformations
(?i:P)P ignoring case ((?i:the) matches The and THE)
(?cn:P) (?c:P) (?c-:P)P with its letters shifted n places along the alphabet; by any of 1 to 25; in Atbash, with the alphabet reversed ((?c1:hal) matches ibm, (?c-:hold) matches slow)
(?r:P)P reversed ((?r:stop) matches pots)
(?Rn:P) (?R:P)P rotated n characters right (left if n is negative); by any amount ((?R:cat) matches atc and tca)
(?tn:P) (?t:P)P with two characters n apart swapped ((?t1:the) matches teh and hte); any two
(?a:P)anagrams of P, which must have finitely many strings, since anagrams of infinite ones may not be regular ((?a:listen) matches silent). (?a:P-^.*) gives sub-anagrams
(?[m:n]:P) (?[m:n:s]:P)P sliced as in Python: characters m up to but not including n, counting from 0 (from the end if negative); every s-th one. Too-short strings are skipped ((?[1:-1]:spam) matches pa)
(?z:P/Q/R) (?Z:P/Q/R)P with a Q replaced by an R; but not at either end ((?z:London/o/u) matches Lundon). To replace at the end or start, write (P-Q)R or R(P_-Q)

Operators like *, < and & are listed from tightest to loosest binding, so !ab<c|d means (!((ab)<c))|d. One of the operators from < to -op can be repeated, as in a-b-c, but different ones need parentheses, as in (a<b)^c.
